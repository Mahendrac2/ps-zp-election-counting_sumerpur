*आधिकारिक मतदान दिवस ट्रैकर (152 बूथ) एवं मतगणना वॉर-रूम कंट्रोल सिस्टम (14 राउंड • 15 टेबल • 21 पं.स. वार्ड • 4 जि.प. वार्ड)*

## 🏠 घर पर काम करने हेतु क्विक स्टार्ट गाइड (Work From Home Setup)

जब आप घर के कंप्यूटर या लैपटॉप पर इस प्रोजेक्ट को शुरू करें, तो नीचे दिए गए 3 सरल स्टेप्स फॉलो करें:

### 1. कोड डाउनलोड / अपडेट करें:
यदि घर के कंप्यूटर पर पहली बार प्रोजेक्ट ला रहे हैं:
```bash
git clone https://github.com/Mahendrac2/ps-zp-election-counting_sumerpur.git
cd ps-zp-election-counting_sumerpur
```
यदि आपने पहले से क्लोन कर रखा है, तो बस लेटेस्ट कोड खींचें:
```bash
git pull origin main
```

### 2. आवश्यक पैकेज इंस्टॉल करें:
```bash
npm install
```

### 3. लोकल सर्वर चालू करें:
```bash
node server.js
```
*(या `npm start`)*

### 4. ब्राउज़र में खोलें:
* **🗳️ मतगणना पोर्टल (Counting Portal):** [http://localhost:3000/counting.html](http://localhost:3000/counting.html)
* **📺 वॉर-रूम टीवी (War Room TV):** [http://localhost:3000/counting.html?warroom=1](http://localhost:3000/counting.html?warroom=1)
* **📋 मतदान प्रगति पोर्टल (Poll Progress):** [http://localhost:3000/index.html](http://localhost:3000/index.html)

## 📌 सिस्टम संरचना एवं मुख्य विशेषताएं (Key Modules)

### 1. 🗳️ मतगणना पोर्टल (14 राउंड • 15 टेबल) — `counting.html`
* **राउंड-वार टेबल कार्ड्स (14 राउंड • 15 टेबल):** 
  * प्रत्येक राउंड के 15 मतदान केंद्रों के EVM मत (17C), CU नंबर, PS व ZP वोट विवरण।
* **21 पंचायत समिति वार्ड परिणाम:** 
  * वार्ड 1 से 21 के लाइव रुझान, विजेता, बढ़त अंतर (Margin), और उपविजेता।
* **4 जिला परिषद वार्ड परिणाम:** 
  * वार्ड 7, 8, 9, 10 के संकलित परिणाम और प्रत्याशी-वार प्रतिशत बार ग्राफ।
* **15 टेबल x 14 राउंड मास्टर मैट्रिक्स:** 
  * समस्त 152 बूथों की 15 टेबल पर स्थिति, 1-क्लिक संपादन (Edit Modal) सहित।
* **मतगणना प्रविष्टि (तालिका दृश्य):** 
  * एक्सेल जैसे टेबल फॉर्मेट में तेज और सुविधाजनक डेटा एंट्री।
* **दायां 3-डॉट टूल्स मेनू (⋮):** 
  * ऊपर हेडर में Google Sheet सिंक, 30s ऑटो-सिंक, मॉक टेस्ट, CSV टेम्पलेट डाउनलोड, Excel एक्सपोर्ट और WhatsApp बुलेटिन एक आधुनिक ड्रॉपडाउन में व्यवस्थित।

### 2. 📺 समर्पित वॉर-रूम टीवी (War Room TV) — बड़ी स्क्रीन / प्रोजेक्टर मोड
बड़ी LED टीवी, वीडियो वॉल एवं प्रोजेक्टर (1080p / 4K) के लिए 100% ज़ीरो-स्क्रॉल लेआउट:

* **सुव्यवस्थित शीर्ष पट्टी (Executive TV Header):**
  * **बाईं ओर (Left):** 🏛️ आधिकारिक शीर्षक एवं **1 से 4 व्यूज का ड्रॉपडाउन मेनू**:
    1. राउंड-वार टेबल (1-15 टेबल ग्रिड)
    2. पं.स. सांख्यिकी (21 वार्ड कार्ड्स)
    3. जि.प. सांख्यिकी (4 वार्ड कार्ड्स)
    4. 12-सेकंड ऑटो-रोटेशन
  * **केंद्र में (Center):** **बड़े और बोल्ड स्कोरबोर्ड कार्ड्स (BJP / INC Stats)**
    * **पं.स. (21):** भाजपा, कांग्रेस, अन्य के बड़े आंकड़े।
    * **जि.प. (4):** भाजपा, कांग्रेस, अन्य के बड़े आंकड़े।
  * **दाईं ओर (Right):** लाइव डिजिटल घड़ी एवं **`⋮ टीवी टूल्स`** मेनू:
    * 🔊 साउंड बीप अलर्ट (घोषणा चाइम चालू/बंद)
    * ⛶ फुलस्क्रीन मोड (F11)
    * 🔄 ऑटो-रोटेशन टॉगल
    * 🚪 बाहर निकलें (Exit)
* **परिणाम कार्ड्स में स्थिति:**
  * **घोषित परिणाम:** `🟢 घोषित` बैज, `🏆 विजेता`, `🎯 जीत का अंतर (+X मत)`, और `🥈 पीछे`।
  * **गणना प्रगति:** `🟡 लीड (पूर्ण/कुल बूथ)` बैज, `👑 आगे`, `📈 वर्तमान बढ़त (+X मत)`, और `🥈 पीछे`।
* **🔥 कड़ी टक्कर अलर्ट (Hot Seat Alert):**
  * जीत-हार का अंतर 100 मतों से कम होने पर कार्ड एवं टिकर पर स्वतः लाल रंग में `🔥 कड़ी टक्कर` चमकेगा।
* **🔔 साउंड बीप अलर्ट (Audio Fanfare):**
  * किसी वार्ड का अंतिम परिणाम घोषित होते ही वॉर-रूम में सुखद ऑडियो चाइम बजेगा।
* **📜 बॉटम लाइव न्यूज टिकर:**
  * स्क्रीन के सबसे नीचे सहज गति में 14 राउंड व 21 वार्डों की लाइव स्क्रॉलिंग पट्टी।

## 🧪 मॉक टेस्ट एवं सिमुलेशन कंट्रोल (Testing Engine)

वास्तविक चुनाव से पहले पूरे सिस्टम को टेस्ट करने के लिए **मॉक टेस्ट मेनू** में 4 विकल्प उपलब्ध हैं:
1. **राउंड 1 भरें (15 टेबल):** 15 बूथों में 17C अनुसार डेटा भरेगा, जिससे सक्रिय राउंड स्वतः **राउंड 2** बन जाएगा।
2. **राउंड 1 से 3 भरें (45 बूथ):** 45 बूथ पूरे कर लाइव रुझान दिखाएगा, सक्रिय राउंड **राउंड 4** बन जाएगा।
3. **पूर्ण चुनाव सिमुलेशन (152 बूथ):** सभी 71,943 मतों की शत-प्रतिशत गणना पूर्ण कर सभी 21 पं.स. व 4 जि.प. परिणाम घोषित कर देगा (`14/14 पूर्ण`)।
4. **डेटा रीसेट (Zero Clean Reset):** समस्त 152 बूथों के मत शून्य (0) कर वास्तविक चुनाव के लिए सिस्टम फ्रेश कर देगा (`सक्रिय राउंड 1/14`)।

## 🛠️ सामान्य ट्रबलशूटिंग (Troubleshooting)

| समस्या | समाधान |
| :--- | :--- |
| `EADDRINUSE: port 3000 is already in use` | पहले से चल रहे नोड प्रोसेस को बंद करें: PowerShell में `Stop-Process -Name node -Force` चलाएं, फिर `node server.js` करें। |
| ब्राउज़र में पुराने बदलाव दिख रहे हैं | ब्राउज़र कैश साफ़ करने के लिए **Ctrl + F5** (हार्ड रिफ्रेश) दबाएं। |
| गिट पर नए बदलाव भेजने के लिए | `git add .` -> `git commit -m "update"` -> `git push origin main` चलाएं। |
| गिट से नए बदलाव लेने के लिए | `git pull origin main` चलाएं। |
